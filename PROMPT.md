## Prompt 1 — Initial build

# BUILD MY PROFESSIONAL FREELANCE DEVELOPER PORTFOLIO — FINAL VERSION

You are an expert Senior Frontend Engineer, UI/UX Designer, Product Designer, Accessibility Specialist, SEO Specialist, Performance Engineer, and Freelance Portfolio Strategist.

Build my complete, production-quality personal portfolio website from scratch.

This is my **professional freelance portfolio**, not a college/student template.

The final website must look premium enough to attract real freelance clients while honestly representing my current experience and skills.

**My profile:** Sahil Thange, Frontend / Web Developer, working toward Full-Stack → Freelance. Current skills: HTML5, CSS3, JavaScript, Figma, Responsive Web Design, UI/UX fundamentals, Git/GitHub. Currently learning: React, TypeScript, Node.js, Express.js, Databases, REST APIs, Authentication, Deployment.

The brief additionally specified: a premium/minimal/professional design direction (avoiding template clichés, gradients, glassmorphism, neon, skill-percentage bars); a plain HTML5 + CSS3 + vanilla JavaScript stack with no React/backend/database/CMS/auth/admin panel; an easily editable project-data structure; a full site structure (nav, hero, value strip, about, skills, services, projects with case studies, process, why-work-with-me, contact, footer); dark/light mode with persisted preference; responsiveness from 320px to 1440px+; subtle animation respecting `prefers-reduced-motion`; accessibility; SEO basics; performance-conscious code; strict content honesty (no fabricated clients, revenue, users, awards, or testimonials); handling for five projects (Expense Tracker, MediScan AI, E-Bike Management Application, Discova, and a "Coming Soon" Mini E-Commerce site); GitHub + Vercel deployment; a README; and delivery as a ZIP.

## Prompt 2 — Polish & launch-readiness pass

Audit, improve, polish, and make the existing portfolio launch-ready — without rebuilding from scratch, converting to a framework/backend, or removing working functionality without a strong reason. Stay on plain HTML5 + CSS3 + vanilla JavaScript.
